# Programmers - Level 3. 고고학 최고의 발견

- [문제출처](https://school.programmers.co.kr/learn/courses/30/lessons/131702 '고고학 최고의 발견')

## 풀이

### 접근

- `완전탐색`

### 설계

- 맨 윗 행의 각 열을 0~3회 회전시키는 모든 경우의 수(`product(range(4), repeat=n)`)를 완전탐색
  - 회전은 선택한 칸과 상하좌우 인접 칸의 값을 `(값 + 1) % 4`로 변경
- 윗 행이 정해지면, 아래 행부터는 바로 위 칸이 `0`이 될 때까지 해당 칸을 반복 회전시켜 순서대로 확정
  - 회전 1회는 값을 1만 증가시키므로, 위 칸 값이 2나 3인 경우까지 없애려면 `if`가 아닌 `while`로 필요한 횟수만큼 반복해야 함
- 마지막 행까지 처리한 뒤 모든 칸이 `0`이면 사용한 총 회전 횟수를 후보 답으로, 아니면 해당 조합은 제외
- 모든 경우 중 최소 횟수를 정답으로 선택
