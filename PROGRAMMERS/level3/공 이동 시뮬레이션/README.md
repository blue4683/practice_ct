# Programmers - Level 3. 공 이동 시뮬레이션

- [문제출처](https://school.programmers.co.kr/learn/courses/30/lessons/87391 'Level 3. 공 이동 시뮬레이션')

## 풀이

### 접근

- `구현`

### 설계

- 쿼리를 역순으로 순회하며 최종 목적지 `(x,y)`에 도달 가능한 시작 구간 `[lo,hi]`를 좁혀나가는 방식으로 구현
  - 행 이동(`command 2,3`)과 열 이동(`command 0,1`)이 서로 독립적이므로 `dp_x`, `dp_y` 두 구간을 따로 관리
- 증가/감소 이동의 역연산(preimage)을 계산할 때 경계에 뭉치는 경우를 분기 처리
  - 감소 이동은 `lo == 0`일 때, 증가 이동은 `hi == 상한`일 때 클램프로 인해 여러 시작점이 한 곳으로 몰릴 수 있음을 고려
- 구간이 비면(`lo > hi`) 그 즉시 `0`을 반환해 불필요한 계산 생략
- 최종적으로 x축 구간 길이와 y축 구간 길이를 각각 구해 곱한 값을 반환
