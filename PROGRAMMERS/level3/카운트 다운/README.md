# Programmers - Level 3. 카운트다운

- [문제출처](https://school.programmers.co.kr/learn/courses/30/lessons/131129 'Level 3. 카운트다운')

## 풀이

### 접근

- `DP`

### 설계

- `dp[i] = [최소 다트 개수, 보조값]` 형태로 관리, `compare`로 다트 개수가 적은 쪽을 우선하고 같으면 보조값이 큰 쪽을 선택
- `1~20` 싱글, `2~40` 더블, `3~60` 트리플, `50`(불즈아이) 네 가지 타격을 순회하며 갱신
  - 싱글과 불즈아이는 보조값을 `+1`, 더블·트리플은 보조값을 그대로 유지해 구분
- `target`이 `20` 이하인 구간은 싱글 한 방으로 초기화(`dp[i] = [1, 1]`)해 기저값 설정
