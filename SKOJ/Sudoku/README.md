# SKOJ - Sudoku

- [문제출처](https://skoj.site/problem/10121 'Sudoku')

## 풀이

### 접근

- `백트래킹`

### 설계

- 행·열·3×3 구역마다 이미 사용된 숫자를 `set`(`row`, `col`, `box`)으로 관리해, 빈칸에 넣을 수 있는 숫자인지 O(1)에 검사
- 빈칸 좌표를 미리 `pos`에 모아 두고 순서대로 `dfs`로 채우며, 한 칸을 시도한 뒤 실패하면 배열과 세 `set`을 모두 원래대로 되돌리는 방식으로 백트래킹
- 해가 유일하다는 조건을 이용해 첫 번째 완성 판을 출력하는 즉시 `1`을 반환해 나머지 탐색을 모두 중단 (`exit` 함수 없이 반환값으로 종료)
