# SKOJ - 가장 가까운 공통 조상

- [문제출처](https://skoj.site/problem/10137 '가장 가까운 공통 조상')

## 풀이

### 접근

- `LCA`(트리, DFS)

### 설계

- 재귀 DFS로 루트(1번 정점)부터 각 정점의 깊이(`levels`)와 직속 부모(`parents`)를 미리 계산, 트리가 한쪽으로 치우쳐도 재귀가 끊기지 않도록 `sys.setrecursionlimit`로 재귀 제한 상향
- 두 정점 `A`, `B`의 깊이를 맞추기 위해 더 깊은 쪽을 부모 방향으로 먼저 끌어올린 뒤, 두 포인터가 같아질 때까지 동시에 `parents`를 따라 한 칸씩 올라가는 방식으로 최소 공통 조상 탐색
