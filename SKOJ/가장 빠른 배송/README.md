# SKOJ - 가장 빠른 배송

- [문제출처](https://skoj.site/problem/10081 '가장 빠른 배송')

## 풀이

### 접근

- `다익스트라`

### 설계

- 도로가 양방향이므로 입력받은 간선을 `graph[u]`와 `graph[v]` 양쪽에 모두 추가한 뒤, 우선순위 큐(`heapq`) 기반 다익스트라로 `1`번 도시에서 `N`번 도시까지의 최소 시간 계산
- 큐에서 꺼낸 거리가 이미 기록된 최단 거리보다 크면 건너뛰어 불필요한 탐색을 방지하고, `N`번 도시에 도달하지 못해 `INF`로 남으면 `-1` 출력
