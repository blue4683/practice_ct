# SKOJ - 가장 빠른 버스

- [문제출처](https://skoj.site/problem/10180 '가장 빠른 버스')

## 풀이

### 접근

- `이분 탐색`(lower bound)

### 설계

- 버스 출발 시각이 오름차순으로 정렬되어 있으므로, 승객 도착 시각 이상인 첫 번째 위치를 찾는 lower bound 이분 탐색으로 탑승할 버스를 결정
  - `a <= arr[mid]`이면 `r`을 줄이고 아니면 `l`을 늘려, 반복이 끝났을 때 `l`이 도착 시각 이후 가장 빠른 버스의 인덱스를 가리킴
- 마지막 버스보다 늦게 도착한 승객은 탐색 없이 바로 `-1`로 처리해 `l`이 범위를 벗어나는 경우를 사전에 차단
- 이미 조회한 도착 시각은 `result`에 저장해 두고 같은 값이 다시 질의되면 탐색 없이 바로 출력
