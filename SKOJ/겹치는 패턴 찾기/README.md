# SKOJ - 겹치는 패턴 찾기

- [문제출처](https://skoj.site/problem/10254 '겹치는 패턴 찾기')

## 풀이

### 접근

- `KMP`

### 설계

- 패턴 `P`에 대한 실패 함수(`pi` 배열)를 먼저 구성해 매칭 실패 시 되돌아갈 위치를 미리 계산
- `T`를 순회하며 KMP 매칭을 수행하되, 패턴 전체가 일치해도 `j`를 `0`이 아닌 `pi[j]`로 되돌려 겹치는(overlapping) 매칭까지 모두 탐지
- 매칭이 시작된 1-indexed 위치(`i - m + 2`)를 `point`에 기록해 개수와 함께 출력, 매칭이 없으면 `print(*point)`가 자연스럽게 빈 줄을 출력
