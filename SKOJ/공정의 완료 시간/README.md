# SKOJ - 공정의 완료 시간

- [문제출처](https://skoj.site/problem/10100 '공정의 완료 시간')

## 풀이

### 접근

- `위상 정렬` + `DP`

### 설계

- `dp[i]`를 `i`번 공정이 끝나는 가장 이른 시각으로 정의하고, 선행 공정이 없는 공정은 자기 소요 시간으로 초기화한 뒤 위상 정렬 순서대로 전파
- 선행 공정이 여러 개인 공정은 모든 선행 공정이 끝나야 시작할 수 있으므로 `max(dp[xx], dp[x] + ts[xx - 1])`로 가장 늦게 끝나는 선행 공정 기준으로 갱신하고, 전체 공정의 완료 시간은 `dp`의 최댓값으로 출력
