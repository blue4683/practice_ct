# SKOJ - 네트워크 복구하기

- [문제출처](https://skoj.site/problem/10016 '네트워크 복구하기')

## 풀이

### 접근

- `유니온 파인드`(union by size)

### 설계

- 두 컴퓨터가 이미 같은 집합이면 케이블을 추가해도 통신 가능 쌍이 늘지 않으므로, `find`로 먼저 확인한 뒤 다를 때만 `union` 수행
- 두 집합을 합칠 때 새로 통신 가능해지는 쌍의 수가 두 집합 크기의 곱과 같다는 성질을 이용해, 전체 쌍 개수(`N*(N-1)/2`)에서 그 값을 바로 차감해 "통신 불가능한 쌍의 개수"를 유지
- `find`는 반복문으로 루트를 찾은 뒤 경로 위의 모든 노드를 루트에 바로 연결하는 경로 압축으로, `union`은 크기가 작은 집합을 큰 집합 아래로 합쳐 트리 편향 방지
