# SKOJ - 뒤죽박죽 보안 패널

- [문제출처](https://skoj.site/problem/10029 '뒤죽박죽 보안 패널')

## 풀이

### 접근

- `BFS`

### 설계

- 3×3 패널 전체를 길이 9의 문자열로 표현해 하나의 상태로 보고, 빈칸(`0`)의 위치에서 상하좌우로 인접한 칸과 값을 교환하는 것을 한 번의 조작으로 간주해 상태 공간을 BFS로 탐색
- 상태별 최소 조작 횟수를 딕셔너리(`dist`)에 저장해 방문 여부 확인과 거리 기록을 동시에 처리하고, 목표 상태(`123456780`)에 도달하는 순간의 값을 반환
- 도달 가능한 상태 수가 유한(`9!/2`)하므로 탐색이 끝날 때까지 목표를 만나지 못하면 도달 불가능한 입력으로 보고 `-1` 출력
