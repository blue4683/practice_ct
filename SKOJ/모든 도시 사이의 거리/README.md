# SKOJ - 모든 도시 사이의 거리

- [문제출처](https://skoj.site/problem/10093 '모든 도시 사이의 거리')

## 풀이

### 접근

- `플로이드-워셜`

### 설계

- 같은 두 도시를 연결하는 도로가 여러 번 주어질 수 있으므로 입력을 받을 때 더 작은 비용만 유지
- 표준 플로이드-워셜 3중 반복문에서 `graph[s][mid]`가 `INF`이면 그 경유지로는 어차피 갱신될 수 없으므로 안쪽 반복을 건너뛰는 가지치기로 불필요한 연산 절감
- 도달할 수 없어 `INF`로 남은 칸은 출력 시 `-1`로 변환
