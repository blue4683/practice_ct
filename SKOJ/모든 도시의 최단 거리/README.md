# SKOJ - 모든 도시의 최단 거리

- [문제출처](https://skoj.site/problem/10253 '모든 도시의 최단 거리')

## 풀이

### 접근

- `플로이드-워셜`

### 설계

- 같은 두 도시를 잇는 간선이 여러 개 주어질 수 있으므로, 입력을 받을 때 `min`으로 가장 작은 비용만 유지하고 자기 자신으로의 비용은 `0`으로 초기화
- 중간 경유지 `mid`를 바깥 루프로 두는 3중 반복문으로 모든 도시 쌍의 최단 거리를 갱신하는 표준 플로이드-워셜 수행
- 이동할 수 없어 `INF`로 남은 칸은 출력 시 `0`으로 변환
