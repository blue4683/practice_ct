# SKOJ - 모든 마을을 연결하는 단순한 방법

- [문제출처](https://skoj.site/problem/10087 '모든 마을을 연결하는 단순한 방법')

## 풀이

### 접근

- `크루스칼(Union-Find)`

### 설계

- 도로 후보를 비용 오름차순으로 정렬한 뒤, 양 끝 마을이 서로 다른 집합에 속한 도로만 선택하는 크루스칼로 최소 비용 계산
- 그래프가 연결되지 않을 수 있으므로 필요한 간선 수(`N-1`)를 `cnt`로 세어 선택할 때마다 차감하고, 끝까지 `0`이 되지 않으면 `-1` 출력 (`M = 0`인 경우도 같은 방식으로 처리)
