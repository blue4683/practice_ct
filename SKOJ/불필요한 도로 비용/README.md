# SKOJ - 불필요한 도로 비용

- [문제출처](https://skoj.site/problem/10283 '불필요한 도로 비용')

## 풀이

### 접근

- `크루스칼(Union-Find)`

### 설계

- 전체 도로 비용의 합을 `result`의 초기값으로 두고, 비용 오름차순으로 크루스칼을 수행하면서 MST에 포함되는 간선의 비용을 하나씩 빼는 방식으로 "전체 - MST" 값을 바로 계산
- 별도로 MST 비용을 따로 구해 빼는 과정 없이, 선택된 간선(서로 다른 집합을 잇는 간선)만 차감해 불필요한 도로 비용만 남김
