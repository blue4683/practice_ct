# SKOJ - 비상구 안내 화살표

- [문제출처](https://skoj.site/problem/10185 '비상구 안내 화살표')

## 풀이

### 접근

- `멀티 소스 BFS`

### 설계

- 모든 비상구(`E`)를 거리 `0`으로 큐에 한꺼번에 넣고 BFS를 수행해, 각 복도 칸에서 가장 가까운 비상구까지의 거리를 한 번의 탐색으로 계산
- 비상구에서 이웃 칸으로 확장할 때 이웃 칸이 가리켜야 할 방향은 이동한 방향의 반대이므로, 탐색 방향 인덱스(`위쪽 이웃 → ^`, `아래쪽 이웃 → v`, `오른쪽 이웃 → <`, `왼쪽 이웃 → >`)에 맞춰 화살표를 바로 기록
- 같은 거리의 후보 방향이 여러 개일 때는 `위, 아래, 왼쪽, 오른쪽` 순으로 인덱스를 매겨 두고, 이미 기록된 화살표와 새 후보 중 인덱스가 작은 쪽(`min`)을 유지해 우선순위 규칙 적용
