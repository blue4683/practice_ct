# SKOJ - 서로 도달할 수 있는가

- [문제출처](https://skoj.site/problem/10279 '서로 도달할 수 있는가')

## 풀이

### 접근

- `플로이드-워셜`(도달 가능성 행렬)

### 설계

- 인접 행렬을 0/1로 구성하고, 중간 경유지 `mid`를 거쳐 두 정점이 모두 연결될 때(`graph[s][mid]`와 `graph[mid][e]`가 모두 1)만 `graph[s][e]`를 1로 갱신하는 플로이드-워셜 변형으로 전이적 폐쇄(도달 가능 행렬) 계산
- 자기 자신으로의 도달 여부는 따로 초기화하지 않아, 실제로 자기 자신에게 되돌아오는 사이클이 있을 때만 자연스럽게 1로 설정됨
