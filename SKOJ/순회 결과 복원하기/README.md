# SKOJ - 순회 결과 복원하기

- [문제출처](https://skoj.site/problem/10197 '순회 결과 복원하기')

## 풀이

### 접근

- `트리`, `분할 정복`

### 설계

- 전위 순회의 첫 원소가 항상 현재 서브트리의 루트라는 점과, 중위 순회에서 루트 왼쪽이 왼쪽 서브트리, 오른쪽이 오른쪽 서브트리라는 점을 이용해 구간을 재귀적으로 분할
- 중위 순회에서 루트의 위치를 매번 탐색하지 않도록 `pos` 딕셔너리에 `정점 번호 → 인덱스`를 미리 저장해 O(1)에 조회, 전체 시간복잡도 O(N)
- 왼쪽 → 오른쪽 서브트리를 모두 처리한 뒤 마지막에 루트를 출력하는 순서로 후위 순회 결과를 바로 생성, 편향 트리처럼 깊이가 깊어질 경우에 대비해 `sys.setrecursionlimit`으로 재귀 제한 상향
