# SKOJ - 스칼라 광주 캠퍼스 소등하기

- [문제출처](https://skoj.site/problem/10167 '스칼라 광주 캠퍼스 소등하기')

## 풀이

### 접근

- `BFS` + `비트마스킹`

### 설계

- 상태를 `(y, x, 지금까지 켠 전등 조합을 나타내는 비트마스크)`로 정의해 BFS 수행
  - 전등 칸은 미리 정수 인덱스로 치환해두고, 처음 방문하는 전등만 해당 비트를 켠 새 상태로 전이시켜 같은 위치라도 켠 전등 조합이 다르면 별개 상태로 구분
- 모든 전등을 켠 비트마스크(`full`)에 도달하는 순간의 이동 횟수를 결과로 반환
