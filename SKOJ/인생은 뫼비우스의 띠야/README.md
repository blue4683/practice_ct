# SKOJ - 인생은 뫼비우스의 띠야

- [문제출처](https://skoj.site/problem/10002 '인생은 뫼비우스의 띠야')

## 풀이

### 접근

- `행렬 거듭제곱`

### 설계

- 점화식 `f(n) = p·f(n-1) + q·f(n-2)` (`f(0)=A, f(1)=B`)를 2×2 행렬 `[[p, q], [1, 0]]`의 `(n-1)`제곱으로 표현해 O(log N)의 행렬 거듭제곱으로 큰 `N`까지 빠르게 계산
- `N = 0`, `N = 1`인 경우는 행렬 연산 없이 바로 `A`, `B`를 출력하는 예외 처리
- 행렬 곱셈과 최종 결과 계산마다 `MOD`로 나눈 나머지를 유지해 오버플로우 방지
