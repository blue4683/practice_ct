# SKOJ - 좌표 이동

- [문제출처](https://skoj.site/problem/10156 '좌표 이동')

## 풀이

### 접근

- `DP`(단계별 상태 갱신)

### 설계

- 각 단계 `i`마다 선택 가능한 이동 목록 `(이동량, 비용)`을 미리 읽어두고, 현재 위치별 최소 누적 비용을 담은 딕셔너리 `cur`를 단계마다 새로 갱신하는 계층별 DP
- 한 단계 안에서 여러 이동 방법이 같은 위치로 도달하면 더 작은 비용만 남겨 다음 단계로 넘기고, 도달 가능한 위치가 하나도 없어지면 즉시 `break`로 종료해 불필요한 계산 방지
- N단계를 모두 거친 뒤 목표 위치 `t`에 대한 최소 비용을 조회, 도달 불가능하면 `-1` 출력
