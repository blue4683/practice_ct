# SKOJ - 중앙값 찾기

- [문제출처](https://skoj.site/problem/10049 '중앙값 찾기')

## 풀이

### 접근

- `투 힙(Two-Heap)`

### 설계

- 하위 절반을 담당하는 최대 힙(`max_heap`, 값에 `-1`을 곱해 저장)과 상위 절반을 담당하는 최소 힙(`min_heap`)으로 나눠 관리
- 두 힙의 크기가 같으면 새 값을 `max_heap`에, 다르면 `min_heap`에 넣은 뒤, 경계가 어긋나면(최대 힙의 최댓값 > 최소 힙의 최솟값) 두 힙의 최상단을 서로 교환해 항상 `max_heap`이 더 작은 값들만 갖도록 유지
- `max_heap`의 크기를 `min_heap`보다 항상 같거나 하나 많게 유지하므로, 그 최상단(`-max_heap[0]`)이 곧 중앙값(짝수 개일 때는 더 작은 쪽 중앙값)이 되어 매 입력마다 바로 출력
