# SKOJ - 천문대 관측팀의 파벌 싸움

- [문제출처](https://skoj.site/problem/10015 '천문대 관측팀의 파벌 싸움')

## 풀이

### 접근

- `유니온 파인드`(union by size)

### 설계

- 각 집합의 인원수를 `size` 배열로 별도 관리하고, `union` 시 크기가 더 작은 집합을 큰 집합 밑으로 합쳐(`union by size`) 트리가 한쪽으로 치우치지 않도록 구성
- 명령 `1`은 두 대표가 다를 때만 합치고, 명령 `2`는 두 대표 비교로 같은 팀 여부 판별, 명령 `3`은 `find`로 찾은 대표의 `size` 값을 그대로 출력
