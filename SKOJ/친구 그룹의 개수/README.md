# SKOJ - 친구 그룹의 개수

- [문제출처](https://skoj.site/problem/10268 '친구 그룹의 개수')

## 풀이

### 접근

- `유니온 파인드`

### 설계

- 친구 관계마다 두 사람의 대표가 다를 때만 `union`으로 합치는 유니온 파인드로 그룹 구성 (같은 관계가 반복되거나 `a == b`인 입력도 자연스럽게 무시됨)
- 모든 관계를 반영한 뒤 `1`부터 `N`까지 `find`를 한 번씩 호출해 경로를 압축하면 `graph[i]`가 각자의 최종 대표가 되므로, `set(graph)`의 크기에서 `graph[0]` 몫 `1`을 뺀 값이 그룹 수
