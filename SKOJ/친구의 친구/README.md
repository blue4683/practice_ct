# SKOJ - 친구의 친구

- [문제출처](https://skoj.site/problem/10094 '친구의 친구')

## 풀이

### 접근

- `플로이드-워셜`(도달 가능성 행렬)

### 설계

- 자기 자신에게는 항상 연락을 전달할 수 있다는 조건에 맞춰 대각선(`graph[i][i]`)을 미리 `1`로 초기화한 뒤 직접 연락 관계를 반영
- 3중 반복문에서 `graph[s][mid]`가 `0`이면 그 경유지를 통한 갱신이 애초에 불가능하므로 안쪽 루프를 건너뛰는 가지치기를 적용해 도달 가능 행렬(transitive closure) 계산
