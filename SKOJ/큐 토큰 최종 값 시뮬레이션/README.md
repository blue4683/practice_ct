# SKOJ - 큐 토큰 최종 값 시뮬레이션

- [문제출처](https://skoj.site/problem/10041 '큐 토큰 최종 값 시뮬레이션')

## 풀이

### 접근

- `큐(Deque) 시뮬레이션`

### 설계

- `1`부터 `N`까지 번호를 `deque`에 담고, 원소가 하나 남을 때까지 선두를 `popleft()`로 제거한 뒤 다음 선두를 `popleft()` 하여 `append()`로 말단에 옮기는 과정을 반복
- deque를 사용해 양 끝 연산을 O(1)에 처리, 요세푸스 문제 형태의 시뮬레이션으로 마지막 남는 토큰 번호 도출
