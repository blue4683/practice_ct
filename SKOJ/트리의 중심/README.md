# SKOJ - 트리의 중심

- [문제출처](https://skoj.site/problem/10139 '트리의 중심')

## 풀이

### 접근

- `리프 제거(Leaf-Peeling)`

### 설계

- `N=1`인 경우 트리의 중심이 자기 자신 하나뿐이므로 `1`을 두 번 출력하는 예외 처리
- 차수가 1인 리프 정점들을 큐에 담고, 남은 정점 수가 2 이하가 될 때까지 라운드 단위(`k = len(q)`)로 현재 리프들을 한꺼번에 제거하며 인접 정점의 차수를 낮추는 방식으로 바깥 껍질부터 벗겨나감
- 이렇게 마지막까지 남는 1~2개의 정점이 곧 트리의 중심(centroid)
