# SKOJ - 트리의 지름

- [문제출처](https://skoj.site/problem/10192 '트리의 지름')

## 풀이

### 접근

- `트리`, `DFS`(스택 기반)

### 설계

- 임의의 정점(`1`번)에서 가장 먼 정점 `x`를 찾고, 다시 `x`에서 가장 먼 정점까지의 거리를 구하면 그 값이 트리의 지름이 된다는 성질을 이용해 탐색을 두 번만 수행
- 리스트를 스택처럼 사용(`pop()`)하는 반복 탐색으로 재귀 깊이 문제 없이 `N`이 최대 200,000인 트리도 처리하고, 탐색 중 거리가 가장 큰 정점을 계속 갱신해 반환
- 정점이 하나뿐인 경우(`N = 1`)는 탐색 없이 `0`을 바로 출력
