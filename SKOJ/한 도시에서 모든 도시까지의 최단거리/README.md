# SKOJ - 한 도시에서 모든 도시까지의 최단거리

- [문제출처](https://skoj.site/problem/10082 '한 도시에서 모든 도시까지의 최단거리')

## 풀이

### 접근

- `다익스트라`

### 설계

- 도로가 양방향이므로 간선을 `graph[u]`와 `graph[v]` 양쪽에 모두 추가하고, 우선순위 큐(`heapq`) 기반 다익스트라로 시작 도시 `S`에서 모든 도시까지의 최소 시간 배열(`dists`)을 한 번에 계산
- 큐에서 꺼낸 거리가 이미 기록된 값보다 크면 건너뛰어 불필요한 탐색을 방지하고, 도달할 수 없어 `INF`로 남은 도시는 출력 단계에서 `-1`로 변환
