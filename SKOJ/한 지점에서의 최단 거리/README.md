# SKOJ - 한 지점에서의 최단 거리

- [문제출처](https://skoj.site/problem/10284 '한 지점에서의 최단 거리')

## 풀이

### 접근

- `다익스트라`

### 설계

- 우선순위 큐(`heapq`)를 이용한 다익스트라로 시작 정점 `S`에서 모든 정점까지의 최단 거리 배열(`dists`)을 한 번에 계산, 큐에서 꺼낸 거리가 이미 기록된 값보다 크면 건너뛰어 불필요한 탐색 방지
- 함수가 특정 도착점이 아니라 전체 거리 배열을 반환하도록 구성하고, 도달할 수 없는 정점(`INF`)은 출력 단계에서 `INF` 문자열로 변환
