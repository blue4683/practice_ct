# SKOJ - 회사 메세지 전달 시스템

- [문제출처](https://skoj.site/problem/10136 '회사 메세지 전달 시스템')

## 풀이

### 접근

- `BFS` + `캐싱`

### 설계

- 정점을 문자열 이름으로 하는 그래프(`defaultdict`)를 구성하고, 질의마다 BFS로 최단 경로(간선 수)를 구해 이미 계산한 출발점의 결과는 `cache`에 저장해 재사용
- 새 질의의 시작점이나 도착점 중 하나라도 이미 캐시에 있으면 새로 BFS를 돌리지 않고 캐시된 결과에서 바로 조회, 둘 다 없을 때만 새 BFS 실행
- 표준 입력을 `sys.stdin.readline`으로 받아 다수의 질의를 빠르게 처리
