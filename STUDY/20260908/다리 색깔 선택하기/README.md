# SKOJ - 다리 색깔 선택하기

- [문제출처](https://skoj.site/problem/10028 '다리 색깔 선택하기')

## 풀이

### 접근

- `비트마스크` + `크루스칼(Union-Find)`

### 설계

- 색깔 선택 조합을 비트마스크로 표현해 켜진 비트 수가 정확히 `P`개인 조합만 완전탐색
- 각 조합마다 비용 오름차순으로 정렬된 28개 간선을 순회하며 선택된 색깔이면서 서로 다른 집합인 간선만 크루스칼(Union-Find)로 연결, 8개 섬이 모두 연결(간선 7개)됐을 때만 비용 합을 최소값 후보로 갱신
