# SKOJ - 달리기 선수

- [문제출처](https://skoj.site/problem/10227 '달리기 선수')

## 풀이

### 접근

- `DP`

### 설계

- 완전제곱수 지점(`i²`)의 `dp` 값을 미리 `0`으로 설정해, 한 구간만으로 도달 가능한 경우 별도의 "정지"가 필요 없음을 표현
- 이후 각 `i`마다 마지막 구간 길이 `j`를 바꿔가며 `dp[i - j²] + 1`로 갱신하는 DP로 (전체 구간 수 - 1)에 해당하는 최소 정지 횟수를 계산하고, 마지막에 `+1`을 더해 실제 필요한 전체 구간(달린 횟수) 수로 변환해 출력
