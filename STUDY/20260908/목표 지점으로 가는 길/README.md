# SKOJ - 목표 지점으로 가는 길

- [문제출처](https://skoj.site/problem/10165 '목표 지점으로 가는 길')

## 풀이

### 접근

- `DFS`(역방향 그래프)

### 설계

- 단방향 도로 `U→V`를 뒤집어 `graph[V]`에 `U`를 저장, `T`에서 뒤집힌 그래프를 따라가면 원래 그래프에서 `T`에 도달 가능한 도시들을 찾을 수 있다는 성질 이용
- 리스트를 스택처럼 사용(`pop()`)하는 반복적 DFS로 `visited` 집합에 도달 가능한 도시를 모두 모은 뒤 개수와 오름차순 목록 출력
