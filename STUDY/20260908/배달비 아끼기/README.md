# SKOJ - 배달비 아끼기

- [문제출처](https://skoj.site/problem/10233 '배달비 아끼기')

## 풀이

### 접근

- `다익스트라`

### 설계

- 상태를 `(노드, 할인권 사용 여부)`로 확장한 2차원 다익스트라 수행 — `dists[v][0]`은 할인권 미사용, `dists[v][1]`은 이미 사용한 상태의 최단거리
  - 할인권이 남아있는 상태(`discount=1`)에서는 간선 비용을 절반으로 나눈 전이를 추가로 시도하고, 사용 후 `discount=0`으로 전환해 재사용 불가능하게 처리
- 힙에서 꺼낸 항목이 이미 갱신된 `dists` 값보다 크면 스킵해 중복 탐색 제거
- 정답은 `dists[t][0]`, `dists[t][1]` 중 최솟값, 둘 다 `INF`면 `-1` 반환
